# 🧬 CrossMatch AI

### AI-powered kidney exchange optimization platform

CrossMatch AI is an Artificial Intelligence platform designed to identify hidden kidney transplant opportunities between biologically incompatible donor-recipient pairs.

The project combines:

* Machine Learning
* Graph Optimization
* Clinical Scoring
* Network Intelligence
* Interactive Visualization

to support smarter and more efficient kidney paired donation programs.

---

# 🚀 Features

✅ Predictive AI for transplant viability
✅ 2-way and 3-way donor exchange cycle detection
✅ Interactive transplant network graphs
✅ Clinical and logistical scoring
✅ Smart matching simulation dashboard
✅ Explainable AI support system

# 📊 AI Model

The predictive engine uses Machine Learning models to estimate transplant viability probabilities between donor-recipient pairs.

Current prototype metrics:

* ROC-AUC ≈ 97%
* High precision and recall
* Explainable scoring approach

---

# 🔗 Graph Optimization

The platform identifies optimized transplant chains using directed graph analysis and cycle detection algorithms.

Supported:

* 2-way exchange cycles
* 3-way exchange cycles
* Non-overlapping optimized matching
